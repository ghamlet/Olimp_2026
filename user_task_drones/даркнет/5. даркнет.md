Darknet это фраемворк для обучения нейронных сетей. Нам необходимо самостоятельно скомпилировать её из исходного кода.

Следующие блоки кода скопируют исходный код darknet из репозитория AlexeyAB в наш Colab, отредактируют Makefile так, чтобы использовать OPENCV (в настоящее время опенсисви убрали из установленных пакетов) и GPU для darknet и затем скомпилируют darknet.


> [!NOTE]
> 
> Ошибка в том, что в Colab нет dev-пакета OpenCV (заголовков + pkg-config). README требует OpenCV при OPENCV=1. Установи его перед !make:
> !apt-get update
> !apt-get install -y libopencv-dev
> !make
> Если OpenCV тебе не нужен для тренировки (нужен только для видео/вывода картинок самим darknet'ом) — можно просто вернуть OPENCV=0 и собрать без него:
> !sed -i 's/OPENCV=1/OPENCV=0/' Makefile
