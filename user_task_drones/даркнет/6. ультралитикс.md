
**Ultralytics** — это современная экосистема и Python-библиотека для задач компьютерного зрения (Computer Vision). Она включает в себя такие популярные архитектуры, как **YOLOv8**, **YOLOv11** и последующие линейки. 

---

## 1. Базовые модели и веса

Модели Ultralytics делятся по размеру на 5 градаций: от самых легких (для мобильных устройств и микроконтроллеров) до максимально точных (требующих мощных GPU).

| Версия / Размер | Файл весов | Параметры (M) | Размер файла (.pt) | Назначение / Применение |
| :--- | :--- | :--- | :--- | :--- |
| **Nano** | `yolo11n.pt` / `yolov8n.pt` | ~2.6M - 3.2M | **~6 - 6.5 MB** | Edge-устройства, Raspberry Pi, мобильные приложения. |
| **Small** | `yolo11s.pt` / `yolov8s.pt` | ~9.4M - 11.2M | **~18 - 22 MB** | Отличный баланс скорости и точности для ноутбуков/CPU. |
| **Medium** | `yolo11m.pt` / `yolov8m.pt` | ~20.1M - 25.9M | **~40 - 50 MB** | Стандарт для серверов при высоких требованиях к mAP. |
| **Large** | `yolo11l.pt` / `yolov8l.pt` | ~25.3M - 43.7M | **~50 - 85 MB** | Для сложных задач и богатых датасетов. |
| **Extra Large** | `yolo11x.pt` / `yolov8x.pt` | ~56.9M - 68.2M | **~110 - 135 MB** | Максимальная точность, когда скорость инференса не критична. |

Отсюда следует что для использования на платфоре потребуется модель  Small

## 2. Сборка датасета и структура файлов

Для задачи **Object Detection** используется следующий формат файлов:

1. **Изображения:** Файлы `.jpg`
2. **Разметка:** Для каждого изображения создается одноименный файл `.txt`. 
   * Текстовый файл содержит нормализованные координаты от `0.0` до `1.0`.
   * Формат строки: `<class_id> <x_center> <y_center> <width> <height>`

### Структура каталогов

```text
my_dataset/
│
├── data.yaml              # Главный файл конфигурации датасета
│
├── images/                # Папка с картинками
│   ├── train/             # Изображения для обучения
│   │   ├── img001.jpg
│   │   └── img002.jpg
│   └── val/               # Изображения для валидации
│       └── img003.jpg
│
└── labels/                # Папка с текстовыми аннотациями
    ├── train/             # Разметка для train (имена совпадают с картинками)
    │   ├── img001.txt
    │   └── img002.txt
    └── val/               # Разметка для val
        └── img003.txt
```


### Пример файла `data.yaml`

Создайте этот файл в корне проекта:

```
# Абсолютный путь к папке датасета (или относительный от точки запуска)
path: /content/my_dataset  

# Относительные пути от 'path' к папкам с изображениями
train: images/train
val: images/val

# Словарь или список классов
names:
  0: person
  1: car
  2: dog
```


## 3. Запуск обучения и флаги отладки

Для запуска обучения в Python-скрипте используется объект `YOLO`.

### Python скрипт (`train.py`)


```
from ultralytics import YOLO

# 1. Загрузка предобученной модели 
model = YOLO("yolo12s.pt")  


# 2. Запуск процесса обучения с отладочными флагами
results = model.train(
    data="data.yaml",        # Путь к конфигурационному файлу
    epochs=50,               # Количество эпох
    imgsz=640,               # Размер входного изображения (в пикселях)
    batch=16,                # Размер батча (автоматический: batch=-1)
    
    # --- ФЛАГИ ОТЛАДКИ И МОНИТОРИНГА ---
    verbose=True,            # Подробный вывод логов в консоль
    save=True,               # Сохранять промежуточные и итоговые чекпоинты (веса)
    save_period=5,           # Сохранять веса каждые N эпох
    exist_ok=True,           # Перезаписывать директорию экспериментов без ошибок
    name="my_detection_run", # Понятное имя папки с результатами
    
    # --- УПРАВЛЕНИЕ РЕСУРСАМИ ---
    device=0,                # Индекс GPU (0), 'cpu' для обучения на процессоре
    workers=4,               # Количество потоков для загрузки данных
    val=True                 # Запускать валидацию после каждой эпохи
)
```

## 5. Использование итоговых весов (Инференс)

После обучения готовые веса будут лежать по пути:

`runs/detect/my_detection_run/weights/best.pt` (или в папке на Google Диске).

- `best.pt` — модель с наивысшим показателем точности (mAP).
    
- `last.pt` — веса последней пройденной эпохи.
    

### Применение весов для распознавания (Python)



```
from ultralytics import YOLO

# 1. Загружаем обученную модель
model = YOLO("path/to/best.pt")

# 2. Прогон через картинку / видео / поток с камеры
results = model.predict(
    source="test_image.jpg",  # Можно передать путь к картинке, папке, видео или '0' (вебкамера)
    conf=0.55                # Порог уверенности (Confidence threshold)
)

# 3. Обработка результатов в коде
for result in results:
    boxes = result.boxes  # Объект с найденными рамками
    for box in boxes:
        cls_id = int(box.cls[0])
        conf = float(box.conf[0])
        xyxy = box.xyxy[0].tolist()  # Координаты [x1, y1, x2, y2]
        
        print(f"Класс: {model.names[cls_id]}, Уверенность: {conf:.2f}, Бокс: {xyxy}")
```

## 7. Конвертация модели под raspberry (айкар)


Для **Raspberry Pi** (3, 4, 5) самым оптимальным форматом с точки зрения сочетания **минимального веса** и **максимальной скорости** является **NNN/NPU (если есть ускоритель)** или **OpenVINO INT8 / NNN / TFLite INT8** для запуска на CPU.

  

На процессорах ARM (Cortex-A), стоящих в Raspberry Pi, лучше всего себя показывают библиотеки **NNN (например, NCNN / ONNX Runtime с ARM NEON)** или **OpenVINO**, а также **TFLite INT8**.

  

Ниже приведены 2 лучших способа получения «самой легкой» модели под Raspberry Pi.

  

## Способ 1. OpenVINO INT8 (Рекомендуется для Raspberry Pi 4 и 5)

OpenVINO прекрасно оптимизирована под архитектуры ARM (включая Raspberry Pi OS 64-bit). Формат INT8 дает минимальный вес модели и задействует векторные инструкции ARM NEON.

  

### 1. Подготовка и экспорт модели (на ПК)

Сначала сгенерируйте квантованную модель. Экспорт лучше запускать на обычном ПК, так как калибровка требует ресурсов:

  

Python

```
from ultralytics import YOLO

# Загружаем вашу модель
model = YOLO("yolov8n.pt")  # или best.pt

# Экспорт в OpenVINO INT8
# Потребуется калибровочный датасет (по умолчанию coco8.yaml)
model.export(
    format="openvino",
    int8=True,
    data="coco8.yaml"  # Укажите путь к вашему датасету для калибровки
)
```

_На выходе получится папка `yolov8n_openvino_model/` с весом около **2 МБ**._

  

### 2. Запуск на Raspberry Pi

Перенесите созданную папку `yolov8n_openvino_model` на Raspberry Pi и запустите инференс:

  

Python

```
from ultralytics import YOLO

# Загружаем OpenVINO модель прямо через Ultralytics
model = YOLO("yolov8n_openvino_model/")

# Запуск детекции
results = model.predict(source=0, show=True)  # source=0 для веб-камеры
```

## Способ 2. TFLite INT8 (Совместим со всеми версиями Raspberry Pi)

TFLite с полным целочисленным квантованием (Full Integer Quantization) дает сверхкомпактный файл `.tflite`, который работает даже на слабых Raspberry Pi 3 / Zero 2 W.

  

### 1. Экспорт в TFLite INT8 (на ПК)

Python

```
from ultralytics import YOLO

model = YOLO("yolov8n.pt")

# Экспорт в TFLite INT8
model.export(
    format="tflite",
    int8=True,
    data="coco8.yaml"
)
```

_На выходе появится файл `yolov8n_saved_model/yolov8n_int8.tflite` весом **~2.2 МБ**._

  

### 2. Запуск на Raspberry Pi

Для быстрого инференса достаточно стандартного пакета `ultralytics` или `tflite-runtime`:

  

Python

```
from ultralytics import YOLO

# Загрузка TFLite модели
model = YOLO("yolov8n_saved_model/yolov8n_int8.tflite")

# Запуск инференса
results = model.predict(source="image.jpg")
```

## Сравнение форматов для Raspberry Pi

|**Формат**|**Размер файла**|**Производительность на ARM CPU**|**Доп. зависимости**|
|---|---|---|---|
|**PyTorch (`.pt`)**|~6.5 MB|Медленно (~2-5 FPS)|Требует тяжелый PyTorch|
|**TFLite INT8**|**~2.2 MB**|Быстро (~15-25 FPS на Pi 4/5)|Легковесный `tflite-runtime`|
|**OpenVINO INT8**|**~2.0 MB**|**Максимальная** (~20-35 FPS на Pi 5)|`openvino`|

## Важные советы для выжимания максимума из Raspberry Pi

1. **Размер входного изображения (imgsz):**
    
    По умолчанию YOLO использует размер $640 \times 640$. Если уменьшить его до $320 \times 320$ или $416 \times 416$ при экспорте, скорость вырастет в **2–3 раза**:
    
      
    
    Python
    
    ```
    model.export(format="openvino", int8=True, imgsz=320, data="coco8.yaml")
    ```
    
2. **64-битная ОС:** Обязательно используйте **Raspberry Pi OS 64-bit**. На 32-битной системах производительность ARM NEON / INT8 значительно ниже.
    
      
    
3. **Охлаждение:** Квантованные модели активно нагружают все ядра CPU — убедитесь, что на Raspberry Pi установлен радиатор или кулер, чтобы избежать троттлинга.
