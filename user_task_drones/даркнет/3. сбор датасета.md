**формат для yolo daknet** 

	<class_id> <x_center> <y_center> <width_> <height_>

- **`class_id`** — индекс класса объекта, целое число (начинается с `0` для первого класса).
- **`x_center`** — X-координата центра бокса, **нормализованная** относительно ширины изображения (значение от 0.0 до 1.0).    
		**значение от 0.0 до 1.0**  - округляют обычно до 6 знаков

- **`y_center`** — Y-координата центра бокса, **нормализованная** относительно высоты изображения (значение от 0.0 до 1.0).
- **`width`** — ширина бокса, **нормализованная** относительно ширины изображения (значение от 0.0 до 1.0).
- **`height`** — высота бокса, **нормализованная** относительно высоты изображения (значение от 0.0 до 1.0)

**Формулы конвертации координат для задачи про автомобили.**

- width = (x_max - x_min) / image_width
- height = (y_max - y_min) / image_height
- x_center = (x_min + (x_max - x_min) / 2) / image_width
- y_center = (y_min + (y_max - y_min) / 2) / image_height

### Запуск конвертации

Формат .json от Labelme содержит координаты полигонов и масок. Для обучения модели YOLO  его нужно сконвертировать.

Самый простой способ — использовать утилиту labelme2yolo:


**1. Установка утилиты**


```
pip install labelme2yolo==0.1.6
```


Если возникает ошибка совместимости с `pydantic` или `pillow`, установите дополнительно последнюю стабильную версию без указания номера, добавив флаг `--no-cache-dir`:


```
pip install --no-cache-dir labelme2yolo==0.1.6
```


**2. Запуск конвертации**

Передайте путь к папке с вашими фотографиями, который вы выбрали как Open dir:


```
labelme2yolo --json_dir /путь/к/папке_с_картинками
```



Утилита автоматически создаст новую папку `YOLODataset/` внутри папки с фотографмиями со следующей готовой структурой:

```
YOLODataset/
├── dataset.yaml          # Готовый файл конфигурации для Ultralytics!
├── images/
│   ├── train/            # Изображения для обучения (80%)
│   └── val/              # Изображения для валидации (20%)
└── labels/
    ├── train/            # .txt файлы с координатами (train)
    └── val/              # .txt файлы с координатами (val)
```


## Но этот формат не соответствуем файлой стуктуре датасета для фреймворка даркнет


поэтому используем скрипт для конвертации форматов

```
import shutil

from pathlib import Path

  
  

# указываем путь до датасета YOLODataset, внутри которого будут папки images , labels

# рядом с этой папкой после выполнения скрипта появиться папка obj в которой будут одновременно фотографии и аннотации

  

PATH = "/home/arrma/PROGRAMMS/Olimp_2026/DARKNET/user_task_cars/test/YOLODataset"

  
  
# здесь ничего не меняем -------------------------------------

SRC = Path(PATH)

OBJ = SRC / "obj"

OBJ.mkdir(exist_ok=True)

  

exts = {".jpg", ".jpeg", ".png", ".bmp"}

  

for src_dir, exts_group in [(SRC / "images", exts), (SRC / "labels", {".txt"})]:

for f in src_dir.rglob("*"):

if f.suffix.lower() in exts_group:

shutil.copy2(f, OBJ / f.name)

  

print(f"Готово. Файлов в obj/: {len(list(OBJ.iterdir()))}")
```
